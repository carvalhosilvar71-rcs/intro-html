Sobre formulários

O que são formulários?

Os formulários são uma das partes mais importantes dos nosso HTML semântico. Ele serve para:

  • Entrada de dados
  • Interação
  • Acessibilidade
  • Validação e envio de informações

Como trabalhar com um form no HTML?

Para começarmos a trabalhar com um formulário dentro de HTML, utilizamos o elemento de < form >.

Esse elemento, representa um formulário interativo.
